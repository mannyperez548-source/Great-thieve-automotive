# Changelog

## 4.0.0 — City Life & Summit Range

Rebuilt from the supplied original project with the requested city expansion: rendered and enlargable purchase snapshots, procedural bump textures, reflection environment and High-quality SSAO; public lobbies and furnished businesses; free home tours; solid arcade traffic and subdivided movement; climbable shared-height mountain terrain; 20 city places and 12 added legal jobs (27 total); directory navigation and paid services.

V4 refinements: incremental catalog-preview queue; render-target restoration; duplicate business-ring removal; explicit City title and service-effect labels; shared vehicle-size helper; swept player collision server checks; size-aware yielding traffic; ground-preserving exit from cars on hills; expanded regression tests; complete source ZIP including city-data.js and setup documentation.

The earlier v3 binary was not available for comparison. This package is a fresh source rebuild with versioned fixes, not a renamed original ZIP.

## Original base

Coastline Expanded 2.0: coastal sandbox, islands, airports, aircraft, homes, jobs, multiplayer, persistent profiles and fictional non-graphic crime missions. Original catalog IDs and save structure retained.
